## ⚙️ How to Compile and Run

Every program is standalone and takes its input from the console.

```bash
g++ -std=c++17 -o bubble_sort bubble_sort.cpp
./bubble_sort
```

On Windows, run the generated `bubble_sort.exe` instead. No external libraries are needed, only the C++ standard library.
